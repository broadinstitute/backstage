# Agent Instructions

## Commits and pull requests

- Write commit messages and PR titles using [Conventional Commits](https://www.conventionalcommits.org/): `type(scope): summary`.
- Use the types already in this repo's history (`feat`, `fix`, `chore`, `docs`, ...) and a scope for the area touched (for example `catalog`, `deps`, `build`).
- Keep the summary human readable: lowercase, imperative mood, no trailing period, and say what changed and why rather than just which file changed.
- Add a commit body when the reason is not obvious from the summary. Reference CVE or advisory IDs there.
- Use the same `type(scope): summary` line as the PR title.
